# Orhun Utku Topal

Computer engineer working on autonomous systems, AI agents and Turkish natural
language processing. Istanbul, Türkiye — open to remote work and to relocating.

I build things that have to survive contact with the real world: a fighter UAV that
flew an autonomous mission, a security gateway that runs on an actual Raspberry Pi
rather than a VM, a language model fine-tuned on a corpus I collected myself.

**[orhunutkutopal.com](https://www.orhunutkutopal.com)** — case studies, documents and
the full record.

---

### Focus

**Agentic AI** — LLM agent architectures, RAG pipelines, tool use, orchestration,
hand-off thresholds to a human.

**Turkish NLP** — LoRA fine-tuning, corpus collection and cleaning, measuring style
and consistency.

**Autonomous systems** — path planning, flight mission design, real-time computer
vision, mechanical integration.

### Selected work

| Project | What it is |
|---|---|
| **[Mısra Makinesi](https://www.orhunutkutopal.com/work/misra-makinesi.html)** | A generative model that writes in the style of 56 Republican-era Turkish poets. Turkish LLaMA 8B fine-tuned with LoRA on a corpus I collected. TÜBİTAK 2209-A funded. |
| **[EdgeShield](https://github.com/OrhunX/edgeshield)** | A hardened IoT gateway on a physical Raspberry Pi 5. TLS transport, HMAC integrity, replay protection, Suricata IDS, and an Isolation Forest layer that catches behavioural anomalies the cryptographic checks cannot. |
| **[Teknofest Fighter UAV](https://www.orhunutkutopal.com/work/teknofest-uav.html)** | Fixed-wing combat UAV, three Teknofest seasons. Mechanical team lead and pilot; A\*-based path planning on the software side. |
| **[Rainbow Lens](https://www.orhunutkutopal.com/work/rainbow-lens.html)** | Real-time iris tracking for virtual contact-lens try-on, integrated with a live product catalogue. |
